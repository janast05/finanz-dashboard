# Finanz-Dashboard – Girokonto Student

Ein Studienprojekt mit fiktiven Kontobewegungen, Kennzahlen, Diagrammen, Statistik, filterbarer Tabelle und Simulator.

## KI-Hinweis

Der Datensatz ist fiktiv und mit Claude (Anthropic) generiert; die Website wurde mit GitHub Copilot erstellt. Personennamen und Nummern sind erfunden, Firmennamen dienen ausschließlich der realistischen Darstellung.

## Datensatz

Die Datei `kontobewegungen_jan-jun_2026_nr2.csv` enthält 112 Buchungen vom 01.01.2026 bis 30.06.2026; der Startsaldo beträgt 850,00 € und der Endsaldo 706,14 €. Die Spalten sind `Date;Recipient/Payer;Payment reference;Amount;Account balance;Category` (Semikolon-getrennt, Dezimalkomma); die Daten sind ebenfalls in `script.js` eingebettet.

## Starten

ZIP-Ordner entpacken und `index.html` per Doppelklick öffnen; ein Webserver ist nicht nötig. Für Chart.js und die Diagramm-Plugins wird eine Internetverbindung benötigt.
